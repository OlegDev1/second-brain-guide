<TLDR>

Если что-то пошло не так, найди здесь свой признак проблемы (симптом), прочитай причину и сделай то, что написано в третьей колонке, как в инструкции к бытовой технике. Ссылка в строке ведёт в главу, где это разобрано подробно. Текст сообщения об ошибке можно вставить в поиск по сайту.

</TLDR>

## Лимит и токены {#limits}

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Лимит кончается после пары сообщений | Каждое сообщение перечитывает всю длинную историю | Одна задача — один поток, решения — в файлы. [Глава 09](/guide/09-tokens-limits#long-chat) |
| Первое сообщение после перерыва съело много лимита | Кэш истёк, история записывается заново | Новую работу — в новый поток. [Глава 09](/guide/09-tokens-limits#practices) |
| Поток пишет **Service is busy** | Достигнут пятичасовой или недельный лимит | Жди сброса или нажми **Stop**. [Глава 09](/guide/09-tokens-limits#limit-hit) |
| Лимит тает, хотя ты ничего не делаешь | Поток следит за PR и просыпается на CI и комментарии | Влей или закрой PR, попроси перестать следить. [Глава 07](/guide/07-agent-team#hidden-costs) |
| Лимит ушёл за первый день | Все потоки на Opus с высоким усилием, много сразу | Не больше двух потоков, модель поменьше. [Глава 07](/guide/07-agent-team#models) |

## Потоки {#threads}

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Поток будто застрял | Ждёт твоего разрешения внутри потока | Открой поток из Overview и ответь. [Глава 02](/guide/02-project#checkpoints) |
| Потоки додумывают вместо вопросов | Дыра в инструкциях проекта или ТЗ | Попроси координатора разобрать ошибки, поправь инструкции. [Глава 02](/guide/02-project#first-run) |
| «Claude ran out of context», поток забыл правило | Сжатие пересказало начало истории | Правило — в `CLAUDE.md` или инструкции, новый поток. [Глава 01](/guide/01-how-agents-work#compaction) |
| Одна и та же ошибка после поправок | Контекст забит неудачными попытками | После двух поправок — новый поток. [Глава 03](/guide/03-specs-prompts#no-circles) |
| Агент говорит «готово», а не работает | Автор проверяет себя плохо | Попроси доказательство, проверь критерии. [Глава 08](/guide/08-testing#author-blind) |
| Новое правило в инструкциях не работает | Изменения видят только новые потоки | Начни новый поток. [Глава 04](/guide/04-project-files#thread-start) |
| Навык или хук из `.claude/` молчит | Облачные потоки их не грузят | Навык — в аккаунт, хук — локально. [Advanced A3](/advanced/a3-claude-code-advanced#where) |
| Потоки не видят репозиторий | Не установлен Claude GitHub App | Установи его и дай доступ к репозиторию. [Глава 05](/guide/05-git-github#git-vs-github) |

## Git и GitHub {#git}

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Конфликт в PR | Две ветки поменяли одно место | Попроси поток разрешить конфликт с `main`. [Глава 05](/guide/05-git-github#conflict) |
| PR двух потоков всё время конфликтуют | Модули правят общие файлы | Один поток — одна папка модуля. [Глава 11](/guide/11-architecture#one-thread-one-folder) |
| Поток не нашёл ТЗ или положил файл не туда | В `CLAUDE.md` нет карты папок | Попроси дописать в `CLAUDE.md`, что где лежит. [Глава 11](/guide/11-architecture#repo) |
| Push отклонён: `non-fast-forward` | На GitHub есть коммиты, которых нет у тебя | В `main` — никогда не форсь, используй revert. [Глава 05](/guide/05-git-github#reset) |
| Поток написал «готово», на GitHub пусто | Работа не закоммичена, песочница исчезла | Коммить и пушь после каждого шага. [Глава 06](/guide/06-sync#commit-often) |
| Работа пропала после отката | Использовали reset вместо revert | Откат только новым коммитом. [Глава 05](/guide/05-git-github#reset) |
| Ключ или пароль попал в коммит | Секрет в истории | Сначала отзови ключ, потом убирай из кода. [Глава 13](/guide/13-security#leak) |

## Деплой и приложение {#app}

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Пустая страница или 404 после деплоя | Сайт собран под другой адрес | Попроси поток сверить базовый путь с именем репозитория. [Глава 12](/guide/12-deploy#pages-sveltekit) |
| Pages показывает README вместо сайта | Источник — ветка, а не GitHub Actions | Settings → Pages → Source → GitHub Actions. [Глава 12](/guide/12-deploy#first-deploy) |
| PWA не обновилась после деплоя | Новая версия ждёт, пока закроются старые вкладки | Попроси поток добавить плашку «Доступна новая версия». [Глава 12](/guide/12-deploy#pwa-update) |
| Таймер врёт после выключенного экрана | Таймер считает секунды, только пока экран включён | Попроси поток хранить время окончания. [Глава 08](/guide/08-testing#timer) |
| Напоминание на час раньше или позже | Следующее время считали как «+24 часа» | Считай по календарю в часовом поясе. [Глава 08](/guide/08-testing#reminders) |
| На ноутбуке приложение пустое | Данные живут в браузере телефона | Экспорт на телефоне, импорт на ноутбуке. [Глава 06](/guide/06-sync#data-on-phone) |
| Данные пропали после очистки сайта | IndexedDB стёрта вместе с данными сайта | Восстанови из JSON-бэкапа. [Глава 06](/guide/06-sync#backup) |
