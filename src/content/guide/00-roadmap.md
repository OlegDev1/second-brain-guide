## Как устроена страница главы {#page}

Сверху всегда видна полоса чтения. Слева в ней глава, в середине раздел, справа поиск и стрелки к соседним главам.

Тонкая линия под полосой показывает, какую часть главы ты уже прочитал.

## Оглавление всех глав {#chapters}

Нажми на название главы в полосе чтения. Снизу откроется список всех глав: Гайд, Advanced и Справочник.

Текущая глава подсвечена. Главы, которые ты дочитал до конца, отмечены галочкой.

### Как закрыть список

Нажми на крестик, на затемнённый фон или выбери главу. Клавиша Escape тоже работает.

## Разделы этой главы {#sections}

Нажми на название раздела в середине полосы. Откроется список разделов, и можно сразу перейти к нужному.

Заголовок, к которому ты перешёл, не прячется под полосой.

### Пример кода

```bash
npm run build
npm run check
```

## Поиск по сайту {#search}

Кнопка с лупой открывает поиск. На компьютере его открывают клавиши / или Ctrl + K.

<Callout type="note">
Поиск работает в собранной версии сайта. Он ищет по названиям глав и тексту.
</Callout>

## Тёмная и светлая тема {#themes}

По умолчанию сайт тёмный. Тему можно сменить внизу страницы или в оглавлении: тёмная, светлая или системная (как в настройках телефона или компьютера).
