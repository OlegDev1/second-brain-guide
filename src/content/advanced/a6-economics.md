Подписка оплачивает разработку в Claude Code, а запросы из самого приложения идут через API и оплачиваются по токенам. Для частых простых вызовов бери маленькую модель: разбор заметки на Haiku 5.5 стоит в двадцать раз меньше, чем на Sonnet 5.5. Ночную аналитику отправляй пакетом за полцены.

## Подписка и API {#plan-vs-api}

Подписка Pro или Max даёт лимит на работу в Claude Code: потоки, координатор, ревью. Платные кредиты сверх лимита считаются по ценам API (проверено: октябрь 2026).

Фичи внутри приложения — голосовой Inbox, «Выбери за меня» с объяснением, анализ дня — ходят в Claude API со своим ключом. Их оплачивают отдельно, по токенам каждого запроса.

| | Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
| --- | --- | --- | --- |
| Вход | 4 | 2 | 0,10 |
| Выход | 20 | 10 | 0,50 |
| Чтение из кэша | 0,20 | 0,10 | 0,01 |
| Для чего | Сложная разработка | Основная работа | Частые простые вызовы |

Цена Haiku 5.5 действует для запросов до 100 тысяч токенов; длиннее — в пять раз дороже (проверено: октябрь 2026).

## Кэш, пакеты, маленькая модель {#savings}

- **Кэш.** Неизменное начало запроса — системный промпт, схема ответа — читается из кэша за 5% цены входа на Opus 5.5 и Sonnet 5.5 (проверено: октябрь 2026). Помогает, только если запросы идут часто: кэш живёт минуты.
- **Пакеты.** Batch API даёт скидку 50% на вход и выход; большинство пакетов готово за час (проверено: октябрь 2026). Подходит для ночного анализа продуктивности, не для кнопки.
- **Маленькая модель.** Разобрать фразу в задачу с датой может Haiku. Opus нужен там, где ошибка дорогая, — в разработке, а не в рутинном вызове.

## Пример: разбор голосовой заметки {#voice-note}

Возьмём [голосовой Inbox](/advanced/a2-integrations#voice-inbox): текст заметки уходит в Claude, а он возвращает задачу в JSON. Допустим, на запрос уходит 1 800 токенов входа (промпт, схема и текст) и 200 токенов выхода, а заметок — 20 в день. Это допущения для примера; подставь свои.

Формула: токены на запрос × запросов в день × 30 × цена.

| | Sonnet 5.5 | Haiku 5.5 |
| --- | --- | --- |
| Вход: 1 800 × 20 × 30 = 1,08 млн | 2,16 $ | 0,11 $ |
| Выход: 200 × 20 × 30 = 0,12 млн | 1,20 $ | 0,06 $ |
| **В месяц** | **≈ 3,36 $** | **≈ 0,17 $** |

Haiku здесь дешевле примерно в 20 раз. Если качество разбора на нём устраивает, Sonnet для этой фичи не нужен.

## Выводы {#takeaways}

<Takeaways>

- Подписка оплачивает работу в Claude Code, а фичи приложения платят за API по токенам отдельно.
- Цена фичи считается просто: токены на запрос × запросов в день × 30 × цена модели.
- Для частых простых вызовов маленькая модель дешевле в десятки раз; Opus оставь для разработки.
- Кэш окупается при частых запросах с одинаковым началом, пакеты — для всего, что может подождать час.
- Цены меняются, поэтому перед расчётом открывай страницу цен, а не эту таблицу.

</Takeaways>
